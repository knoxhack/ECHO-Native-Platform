# API Reference

This page is the public index for ECHO Native beta APIs.

## Public Packages

- `echo-native-contracts`: loader/runtime SPI, typed host services, descriptors, mutation receipts, runtime lanes.
- `echoaddonapi`: addon author API.
- `echoadaptercore`: typed bridge services for registry, lifecycle, events, config, network, resources, world/save data, rendering, screens, attachments, and capabilities.
- `echo-native-testkit`: fake hosts and parity assertions for addon tests.
