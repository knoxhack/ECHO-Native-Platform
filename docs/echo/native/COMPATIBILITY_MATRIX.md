# Compatibility Matrix

| Surface | Public Beta Support |
|---|---|
| Java | Java 25 |
| Minecraft/runtime | `26.1.2` workspace target |
| Native Loader | `0.1.0` public beta lane until release metadata is bumped |
| SDK | `0.1.0` public beta lane until Maven artifacts are published |
| Windows | Supported local verification lane |
| Linux | Not public-supported until CI/runtime evidence is attached |
| macOS | Not public-supported until CI/runtime evidence is attached |
| NeoForge direct addon runtime imports | Unsupported |
| NeoForge compatibility backend | Supported as AdapterCore backend only |
| Dev classpath fallback in release mode | Unsupported |
| Metadata-only mutation claims | Unsupported |

Per-addon migration evidence is generated by `generatePlan2NativeMigrationLedger`. Public release evidence is generated by `generatePlan3ReleasePrepReport`.
